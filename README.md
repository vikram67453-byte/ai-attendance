# 🎓 AI Attendance System

A real-time face recognition based attendance system built with Streamlit.

## 🔴 Live Demo
👉 [Click here to open app](https://ai-attendance-2lcq5lqw4ebynshcxirfmf.streamlit.app)

## ✨ Features
- 📷 Real-time face recognition via camera
- 😊 Emotion detection
- 📊 Attendance records with date & time
- ⬇️ Download attendance as CSV

## 🛠️ Technologies Used
- Python
- Streamlit
- OpenCV
- Scikit-learn (SVM)
- SQLite
- Pandas

## 👨‍💻 How to Run Locally
pip install -r requirements.txt
streamlit run app.py
